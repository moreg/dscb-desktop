# 正文精修与朱雀反馈检查

现有精修已经提供候选隔离、整章与选区、独立事实/目标核验、版本检查、历史快照及撤销。但此前没有朱雀接口或真实检测结果输入，不能据本地 ready 状态证明朱雀全绿；通用的目标描述也不足以保证只改标黄位置。

本次补齐：

- 在原面板增加手动标黄反馈目标。片段必须逐字匹配当前正文，重复位置与重叠拒绝执行；程序只拼接获准替换，范围外文字不交给模型重写。
- 普通精修也显式使用场景自然度和对白保真规则。独立核验须引用真实前后改动；标黄模式逐段检查全部修改，不能以一个片段代表全篇改善。
- 标黄候选只有完整核验通过才可整体采用；普通精修的人工逐条挑选保留原有行为。保真拒绝不会因人工填写全绿而被解除。
- 人工复测登记绑定候选全文 SHA-256，来源明确标为 manual。原稿、原始标黄、原稿概率、候选及每次实际登记结果留档；新候选不会继承旧全绿记录，改稿后界面提示不匹配。无需检测服务账号，不自动上传。
- 最多一次生成、一次补救，用户决定采用或重新指定范围；仍有标黄和概率回升都不会自动启动新一轮或扩大修改范围。

验证包括多片段拼接后范围外字符完全一致、重复/过期/重叠输入拒绝、越权替换拒绝、核验覆盖不足不采用、保真拒绝时人工全绿不放行、采用/撤销、旧候选登记失败，以及 IPC、preload 和面板交互。

本次验证使用模拟模型与人工登记数据，没有真实小说的朱雀前后检测样本，不能宣称已达到全绿或真实降分。实际效果应采用同一检测口径比较原稿和候选，并同时人工审阅事实、人设、对白与衔接。规则和流程通过验证不等于检测器结果保证。
