# 中短篇写作使用指南

从左侧「书案」区域打开「中短篇」。这里有独立的作品列表，无需先创建长篇项目。

## 创建作品

选择新建短篇或中篇，填写作品名、题材、故事设定和写作要求。默认值是短篇 8000 字 / 4 节、中篇 30000 字 / 12 节；这是便于开始创作的预设，并非文学篇幅分类标准。

全文目标支持 1000—120000 字，分节支持 1—60 节。每节预算最多 6000 字，较长的作品需要增加分节数。预算按节均分，余数分给前面的节，总和始终等于全文目标；实际写作以剧情完成度为准，不要求机械凑字数。

新建表单会自动保存本机草稿，包括书名、题材、梗概、要求和篇幅。短篇与中篇分别保存，再次进入栏目或打开对应新建表单时可以继续填写。关闭表单会保留草稿；明确丢弃草稿才会清理。创建成功后清理已提交的草稿，创建失败时保留输入。缓存无法写入时会提示，可先复制草稿。

## 短篇脑洞生成

新建短篇时，以及已有短篇的「作品设定」中，可以使用「脑洞生成」。填好题材和写作要求，再补充想写的方向，例如「婚礼当天发现身份调换」；没有具体方向也可直接生成，不要求先填写作品名或创建作品。

每次请求三个可选脑洞，分别列出故事梗概、开篇钩子、关键反转与结局。可以「换一批」探索不同点子；停止或生成失败时，上一批候选和已收到的恢复文本仍会保留。程序核对最近方案的标题和完整设定，过滤重复结果；若模型只返回部分有效方案，会保留可用的脑洞并提示数量。

脑洞历史保留最近五批完整方案，可以回看并采用。喜欢的方案可收藏，每个工作区最多三十个；收藏独立于最近批次，不会因换批被替换。新建短篇成功后，这份脑洞记录会带到新作品中。历史、收藏和草稿保存在本机，缓存空间不足时会显示提示。

可以针对一个方案定向改写：只改反转、只改结局、调整情绪，或填写自定义要求。反转和结局模式保留其他字段；情绪模式保留书名、故事设定与开篇钩子；自定义模式保留书名和故事设定，调整开篇钩子、反转或结局。新结果单独展示，原方案仍保留，检查后可采用或收藏。

点击「采用这个脑洞」将选中方案填入故事梗概；新建作品名为空时会同时填入建议书名。在手动修改书名前，改选方案也会更新建议书名。已有梗概会先提示是否替换。采用后可继续编辑，再创建或保存作品，并生成全文大纲。已有的大纲和正文需要对照新梗概重新核对。

脑洞使用「开局/大纲」模型路由。候选保存在本机恢复缓存中，采用方案后仍需创建或保存作品，才会写入作品文件。

模型返回内容夹带格式示例、代码围栏或尾逗号时，会尝试提取有效方案；格式容错不额外调用模型。无法提取时保留原始文本，便于复制或自行整理。正常生成只显示状态，恢复文本可按需展开。

## 从设定写到结局

1. 在「作品设定」中交代主角、核心冲突、关键关系和希望达成的结局。需要固定视角、文风或避开的桥段时，填入写作要求。
2. 在「全文大纲」生成或手动填写完整计划。AI 大纲包含人物动机、因果链、逐节推进、伏笔铺设与回收、最终结局。阅读候选并采用后保存。
3. 在「分节正文」依次选择各节并生成。当前节已有正文时，生成只续写新增内容；前面的节为空时会提示先写前节。可以填写本次补充要求，也可以直接手动编辑。
4. 检查生成候选后采用。候选不会自动替换正文，采用后仍需点击「保存作品」。停止或失败时，原稿保持原样，已收到的候选仍可检查、复制或采用。
5. 所有节都有正文后，在「完结检查」检查全文。报告核对动机、因果、反转公平性、视角、人设、伏笔回收、结局、节奏及表达，并要求提供具体原文证据和修改建议。所有节非空只是允许发起检查，不表示作品已经完结或质量通过。
6. 采用检查报告后，在报告下方选择有问题的分节，点击「按检查结果修订」。也可在「分节正文」点击「按检查结果修订这一节」。模型结合完整正文、检查报告和本次补充要求，生成所选节的完整修订稿；原节会显示在旁边，便于核对。点击「采用修订并替换第 N 节」只替换该节，采用后保存作品，再重新检查全文。停止或失败的修订稿仅供复制和手动编辑，不能作为完整稿替换整节。

末节写作要求结束主冲突，兑现开篇承诺与关键伏笔；合理留白可保留，但不能把主线解决推给续作。检查结果是 AI 审阅意见，仍需结合实际正文判断和修改。

## 调整、保存和恢复

调整全文目标或分节数后应用篇幅设置，再保存。已有正文的末尾分节不能通过缩减节数删除，避免调整预算时丢稿。修改设定、大纲、节标题或正文会使旧检查结果失效，改完后重新检查全文。

未保存的编辑和生成候选会尝试写入本机恢复缓存，再次打开作品时可恢复。若缓存空间不足，页面会明确提示；此时应及时保存或复制稿件。作品保存使用历史快照，发生文件写入失败时，上次成功保存的版本仍可读取。

候选区会区分「正在生成/修订」「完成，待采用」「失败」与「已停止」。等待模型首次返回时会明确显示等待状态；失败原因放在候选旁，并随恢复稿保留。失败或停止后可以直接重试，重试沿用原候选对应的分节和本次要求。重新打开页面看到的中断恢复稿表示上次任务已结束，不会在后台继续生成。

多个窗口或文件夹中的外部编辑可能使当前窗口过期。保存时会检查 revision 和稿件指纹，发生冲突时保留当前草稿。可用「重新读取已保存版本」取得最新稿，重读前先保留或复制需要合并的草稿；不要反复用旧稿覆盖更新。

## 导出和文件位置

栏目顶部「保存位置」显示当前作品目录。点击「选择文件夹」可以指定中短篇作品的保存位置；新建表单也会显示作品将保存到哪里。该位置对整个中短篇栏目生效，短篇和中篇共同使用，重启后保留选择。

切换时会复制已有作品及全部历史快照到新目录，原文件保留。新目录中已有的其他作品会一起显示；如存在相同作品编号但内容不同的副本，会提示冲突并保持原保存位置，请另选空文件夹。复制或设置保存失败也不会切换目录；已完整复制的副本可能留在目标目录，重试时可复用。恢复草稿、脑洞历史与收藏仍在本机应用缓存中，选择作品目录不会将这些缓存导出。

默认位置是应用用户目录下的 `short-stories/`；Windows 通常为 `%APPDATA%/ai-writer-desktop/short-stories/`。每部作品保存在当前保存位置下的 `<作品ID>/` 文件夹。「作品文件夹」打开对应目录；「导出全文」先保存当前作品，再单独选择 Markdown 文件的导出位置。

`current.json` 指向当前完整快照。各次保存的快照位于 `revisions/<快照ID>/`，其中 `metadata.json` 记录设定和节标题，`大纲.md`、`审核.md`、`正文/01.md` 等保存文本。旧快照保留，可从作品文件夹取回历史稿；本栏目目前没有历史版本切换界面。

模型配置仍在「设置 → 模型服务」中管理。大纲、正文（含修订）、完结检查分别使用现有的开局/大纲、正文、审稿模型路由。本栏目目前不自动执行章节页的轻度去 AI 味和长篇记忆同步。
