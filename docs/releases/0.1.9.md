# 大神持笔 桌面版 0.1.9

## 新增功能

- 新增番茄榜单工作台，支持榜单采集、标签统计、书籍详情、章节缓存与正文阅读。
- 支持分析分类黄金前三章、按榜单生成脑洞并转为小说项目；采用的前三章方向会保存到项目，生成对应细纲时自动参考。
- 支持按项目配置使用番茄或七猫写作规则。

## 优化与修复

- 新建小说直接使用小说名称作为本地文件夹名；同名目录提示冲突，不覆盖已有文件。未修改作品信息也可保存，将旧 UUID 文件夹同步为书名。
- 完善长短篇脑洞设定卡、短篇证据与结局约束，并同步手机端脑洞输入。
- 优化去 AI 味检查、叙事衔接与动作表达规则，以及正文审核和批量写作恢复流程。
- 优化章节批量读取，减少重复目录扫描。
- Codex 在未输出正文时意外退出可自动重试一次，并保留退出诊断信息。

## 升级方式

- 可直接运行新版 Windows x64 安装包升级现有安装。
- 正式 Release 发布并包含安装包、`.exe.blockmap` 和 `latest.yml` 后，已有自动更新功能的版本可在“设置 → 应用更新”检查并下载新版。
