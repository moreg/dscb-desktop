# 大神持笔 桌面版 0.1.49

## 一键同步优化

- 默认只更新记忆索引、对照细纲、提取记忆并生成章节概要；节奏评估和图解生成改为按需勾选，减少额外模型调用。
- 同步前检查正文是否已保存，各分析步骤使用同一份正文快照。编辑正文或切换章节时取消旧分析流，避免旧结果回填。
- 重复同步时，在正文、相关文件、规则和模型配置不变的情况下复用本面板内的有效分析，只补跑失败项。概要仍经过后端有效性核验。
- 写后自动记忆提取与手动同步可复用输入、已知实体、生成参数和模型完全一致的近期提取结果；应用记忆时仍核对正文与证据。
- 新增总耗时、分步耗时与状态展示，明确区分「分析完成，待确认」「已保存」「复用有效分析」和「失败，可补跑」。
- 新增「重新分析全部」，可强制重跑所选步骤；一键同步中的节奏评估仅生成待确认结果，不直接回写。

本次更新保留已有作品、正文、记忆及设置。无法确认模型身份时不复用分析；关闭面板后不保留面板内的分析完成记录。
