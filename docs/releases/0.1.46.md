# 大神持笔 桌面版 0.1.46

## 新增功能

- 补跑横幅支持「删稿重写」：对修不好的章一键清空正文、概要与章节剧情点并解除全部隔离，回到待生成状态直接重新续写——AI 直出下重生成远快于持续修补。细纲不改动，重生成前请先检查细纲是否被旧稿带偏。
- 长篇冲突修复加预算上限：一轮修复后重跑核对仍不收敛就立即停手，明确报告"建议删除本章正文重新生成"，不再成小时空转；单次修复内部重试轮数 3 → 2。

## 优化与修复

- 删稿重写会同步清除该章概要与按章记录的剧情点，避免被清掉的旧稿内容再以历史引句的形式漏进后续章节。
