# 大神持笔 桌面版 0.1.43

## 新增功能

- 章节列表新增「补跑待核对章节」：批次未跑完时又开了新批次、恢复记录被覆盖的场景，此前只能手改状态文件解锁，现在用该入口即可——复用已保存正文按章号升序补跑完整检查与修复（不重新生成），通过即解除批次隔离；正文已丢失的章节直接清除残留隔离记录。
- 补跑横幅实时显示进度与耗时：每章开始、核对、自动修复、记忆同步等步骤逐条可见，并显示已运行时长；此前批次恢复流程不对外报步骤，界面会长时间停在"准备补跑"让人误以为卡死。

## 优化与修复

- 长篇核对拦截提示区分两种情况：批量写作留下的批次隔离指向章节列表的「补跑待核对章节」，单章待核对指向「重新同步 / 补跑同步」；不再出现照提示同步却始终解不开拦截的空跑。
- 续写与按要求修改交稿时查出长篇冲突，现在由 AI 按冲突明细自动修正、独立复核并重跑核对，修复稿直接替换交付，全程无需手改正文；修复失败时保留当前稿，报错同时附原始冲突与失败原因。
- 补跑与批量续写共用并发锁：补跑期间不能开启批量任务，批量进行中也不能补跑，避免同时改同一批章节。
