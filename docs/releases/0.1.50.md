# 大神持笔 桌面版 0.1.50

## 新增功能

- 精修正文支持单条采用：对比里每处改动可单独写入正文，不必整章一次采用。核验未通过时仍可挑选单条；整章采用仍需核验通过。
- 精修面板可拖成浮动窗口，位置按作品记住。
- 设置 → 功能模型分配新增「精修正文」。修改方案、生成候选、补救和独立核验共用这一路由，不再跟随正文生成或审稿质检。

## 优化与修复

- 章节列表将「草稿」「已润色」统一显示为「正文」；空白正文文件保持「待写」，定稿单独一档。
- 一键十章与手机批量续写累计总耗时和逐章耗时；暂停与重启之间的空档不计时。
- 整章自动去 AI 味的对白验收仍检查旁白叙事；对白通过不能替代叙事检查。诊断失败时保留原稿并提示复核，同一候选复用诊断结果。
- 审核、保真修复与质检建议统一使用共享分段规则：对白中间不用句号，完整陈述句保留句末标点。共享规则版本升至 2026-10-28.1。
- 添加模型服务时记住本机上次填写的地址和密钥。

本次更新保留已有作品、正文、记忆及设置。精修正文未单独指定模型时走当前默认 provider。实际生成速度与精修效果取决于模型、章节长度和内容；自动核验不能替代作者通读。
