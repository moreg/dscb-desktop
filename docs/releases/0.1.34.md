# 大神持笔 桌面版 0.1.34

## 新增功能

- 新增正文导入，支持 TXT、Markdown、多文件及分卷文件夹，提供章节预览、编码选择、重复与缺章检查，并创建独立作品，保留原文件。
- 新增逐章朱雀复测记录，保存整章送检快照、校验指纹及人工登记结果；正文、标点或排版变化后提示重新检测。

## 优化与修复

- 统一正文保真规则，保留语意段落、合法标点和事件顺序；新写内容默认以一句一段为主，允许自然合段，不再强制对白比例。
- 优化去 AI 味的事实核验和场景修复，建议级提示不再阻断已通过事实核验的润色，事实差异及阻断问题仍保留原稿。
- 改进续写上下文准备、长期核对和概要读取的并行处理，细化准备、等待首字及输出阶段的进度提示。
- 改进模型调用、超时处理及续写上下文恢复。

朱雀结果由用户实际送检后人工登记，本应用不会自动调用朱雀，也不保证检测分数。
