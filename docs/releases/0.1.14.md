## 更新内容

- 连续写作前自动补齐缺失的细纲、前文资料和章节概要，兼容旧 JSON 细纲的读取、更新及后续章节联动。
- 明确的章节衔接矛盾会自动局部修复，经过独立复核、自检和细纲检查后保存；复检未通过时自动延迟重试，通过后同步记忆并继续下一章，支持主动停止。
- 手动去 AI 味验收未通过时保留候选稿、差异和检查反馈，可选择“应用候选稿”或“不应用，保留原文”，不再只显示错误并禁用应用。
- 章节概要原文依据匹配失败时自动重新提取和修复；标点、空格差异会归位到真实原句，多次失败时保留有效旧概要或用真实原文摘录兜底，无需手动重新同步。
- 加强修复、同步和概要更新时的正文版本校验，避免旧结果覆盖新稿；修复快速编辑导致的记忆、摘要缓存旧值及人物卡覆盖问题。
- 桌面端和手机端显示衔接自动修复进度；Antigravity 保留超长输入截取方式，不因长度暂停。
