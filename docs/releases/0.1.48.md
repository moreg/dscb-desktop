# 大神持笔 桌面版 0.1.48

## 新增功能

- 正文编辑器新增「精修正文」，支持整章、选区和自定义目标，提供原文对比、独立核验、手动采用及撤销。候选稿可恢复，正文变化时不会被旧候选覆盖。
- 可按作品开启写完后自动生成精修候选，默认关闭，候选不会自动覆盖正文。
- 一键十章及批量续写新增总耗时、逐章耗时，每秒更新；暂停不计时，继续和重试累计耗时。

## 优化与修复

- 章节列表将「草稿」「已润色」统一显示为「正文」；空白正文文件保持「待写」。
- 单章续写与批量写作共享每章本轮的自动修复预算。自动表达修订最多两次，重复旧稿或连续出现相同核验问题时停止，保留原稿和具体问题。
- 续写交稿中的衔接修复后保留事实复核，不再重复启动整章润色；尚未重新验收的表达明确标记为待复核。
- 批量恢复可复用正文、上下文和模型配置均未变化的已验证阶段；区分流程完成与质量验收通过。
- 采用精修稿时检查正文与上下文变化，并保护其他窗口产生的新草稿备份。

本次更新保留已有作品、正文、记忆及设置。实际生成速度与精修效果取决于模型、章节长度和内容；自动核验不能替代作者通读。
