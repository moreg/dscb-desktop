# 大神持笔 桌面版 0.1.10

## 优化与修复

- 完善正文对白质量检查、整场交谈复核与定向修订，优化自动去 AI 味的事实核对、重试次数和进度提示；未通过检查时保留原稿并提示待复核。
- 统一开书、大纲、细纲与审核规则，按项目平台生成章名，减少模板化规划与提前剧透。
- 优化番茄榜单标签筛选、开篇分析缓存和脑洞质量验收，检查因果逻辑、机制差异与指定标签的落实。
- 改进封面风格控制与换方案生成，强化二次元媒介约束，并同步当前画风选择和画面要求。
- 优化章节上下文准备、正文召回、记忆读取与统计，以及榜单分析和脑洞流式显示，减少重复读取和等待。

## 升级方式

- 运行 Windows x64 安装包升级现有安装。
- 正式版发布后，可在“设置 → 应用更新”检查并下载新版。
